## Authentication recovery

- 自动续期必须覆盖 `204 / 401 / 429`，不能只覆盖 `401`；依据是 WQBRAIN 环境中 `wqb.WQBSession` 的 `expected` 判定。
- 所有 `WqbClient` 默认启用全局自动续期：每轮认证最多 3 次，业务请求最多额外重放 3 次，成功后更新 cookie。
- `sqlitesimu` 在 CoreClient 耗尽后独立补 5 次显式重登；额外层不递归进入 CoreClient 的重试循环。
- 两层均耗尽时，`204 / 401 / 429` 不得消耗 runtime 失败预算或写成 `PERMANENT_FAILURE`，任务保持 RUNNING 并延期恢复。
- 为保持与 `WQBSession` 一致，`POST /simulations` 返回 `204` 时也会重登并重放；认证接口自身禁止递归续期，登录仅接受 `201`。
- 旧 cookie loader 曾把同一个值同时挂到父域和 API host，导致续期后同一进程混发新旧 cookie；登录前必须清除旧 BRAIN cookie，旧扁平格式只加载一个 host cookie。
- alpha 等待和 simulation 轮询不得直接绕过 `WqbClient`，也不再保留局部 Basic Auth 重试。
