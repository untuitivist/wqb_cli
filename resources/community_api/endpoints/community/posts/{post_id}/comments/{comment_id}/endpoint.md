# /api/v2/community/posts/{post_id}/comments/{comment_id}.json

Read, explicitly update or delete one comment.

Methods: GET, PUT, DELETE.

Source: https://developer.zendesk.com/api-reference/help_center/help-center-api/post_comments/

Use community api show/params for the exact JSON contract; community api call shares the authenticated transport with resource commands and sqlitecom sync. Write methods have not been executed during release verification.
