# /api/v2/help_center/community_posts/search.json

Search online posts; offset pagination and a maximum of 1000 search results. Do not use search as the sync index.

Methods: GET.

Source: https://developer.zendesk.com/api-reference/help_center/help-center-api/help_center_search/

Use community api show/params for the exact JSON contract; community api call shares the authenticated transport with resource commands and sqlitecom sync. Write methods have not been executed during release verification.
