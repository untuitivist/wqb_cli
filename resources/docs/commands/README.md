# WQB CLI Command Documentation

This directory documents WQB CLI commands in a command-tree layout inspired by Lark/Feishu CLI documentation:

- command namespace first, for example `auth/login`, `alpha/get`, `simulations/create`;
- one command folder per callable action;
- `README.md` for command contract and usage;
- `notes.md` for operational experience and failure modes;
- `examples/args.md` for direct argument examples with real output pointers;
- `examples/io.md` for file-IO examples with real fixtures and outputs;
- `fixtures/` for input files used by examples;
- `outputs/` for real output files generated by running the examples.

Current command nodes:

- `auth/login`
- `auth/status`
- `alpha/get`
- `alpha/check`
- `alpha/recordsets`
- `community/export`
- `community/search`
- `community/stats`
- `config`
- `docs`
- `local-data`
- `shortcut`
- `scope`
- `simulations/create`
- `simulations/get`
- `simulations/options`
- `search/query`

API command examples are real CLI runs against `api.worldquantbrain.com`.
Local-data command examples such as `community` and `scope` are real CLI runs against files under `wqb_cli/local/`.

Local-data inputs come from the WebDataScope browser plugin:

- Source plugin: [leetesla/WebDataScope-WorldQuant](https://github.com/leetesla/WebDataScope-WorldQuant)
- `community`: plugin/browser community cache exported as `WQPCommunityState_*.json` or `WQPCommunityState_*.wqcs`.
- `scope`: plugin-provided network-disk dataset-analysis files placed under `wqb_cli/local/data_all/`.
