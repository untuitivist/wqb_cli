# Local Data

`wqb` has two data sources. Keep them separate:

- API commands call `https://api.worldquantbrain.com`.
- Local-data commands read files under `wqb_cli/local/`.

The local data used by `wqb community` and `wqb scope` comes from the WebDataScope browser plugin:

- Source plugin: [leetesla/WebDataScope-WorldQuant](https://github.com/leetesla/WebDataScope-WorldQuant)
- Community data: extracted from plugin/browser cached community data, then imported into local SQLite.
- Dataset analysis data: downloaded from the plugin-provided network-disk data package. The plugin README states that the `data` folder is not included in the repository.

Do not commit local data. Treat it as user-local runtime input.

## Directory Layout

Place local files like this:

```text
wqb_cli/
  local/
    .env                         local credentials fallback, optional
    config.json                  local CLI config, optional
    auth/
      cookies.json               login cookie cache
    community/
      WQPCommunityState_*.json   WebDataScope community export
      WQPCommunityState_*.wqcs   compressed WebDataScope community export
      community.sqlite3          generated by wqb community export
    data_all/
      info_data.bin              compressed msgpack quick index
      all_data.pickle            full REGION_DELAY alpha dataframes
      main.ipynb                 original loader notes, optional
```

## Commands

Community commands:

```powershell
wqb community export --source wqb_cli/local/community/WQPCommunityState_20260505_141911.json
wqb community stats
wqb community search alpha --limit 3
```

Scope/data_all commands:

```powershell
wqb scope files
wqb scope list
wqb scope top USA_1 --group datafield --min-count 5 --limit 10
wqb scope pickle-summary USA_1 --sample 1
wqb scope alpha-rows USA_1 --table os --datafield volume --limit 3 --columns id,sharpe,fitness,turnover,margin
```

## Source Boundaries

`wqb community` does not call WorldQuant BRAIN APIs.
It searches a local SQLite database generated from WebDataScope community exports.

`wqb scope` does not call WorldQuant BRAIN APIs.
It reads `info_data.bin` for quick aggregate screening and `all_data.pickle` for detailed alpha rows.

The API inventory and command docs under `wqb_cli/resources/api_inventory/` are package resources.
They are not local runtime data and should be committed.
